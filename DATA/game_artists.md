# Game Artists: 15th–18th Century, 4+ Works

Artists with at least 4 works catalogued in the J. Paul Getty Museum collection,
working in the 15th through 18th centuries. Derived from `DATA/artists.xls`, which
only tags works by century bucket (not decade), so this covers the `14-16C`, `17C`,
and `18C` buckets — the closest available match to "15th–18th century" (the `14-16C`
bucket also includes some 14th- and 16th-century works). "Unknown artist/maker" is
excluded; everything else Getty tags as a maker is included as-is (painters, manuscript
illuminators/workshops, manufactories, etc.) — not filtered by medium or fitness for
a painting-matching puzzle. See `getty-artists-xls-data` memory for the source data's
format and quirks.

**Total Works corrected for artists with 5–25 works:** counts for the 106 artists
in that range were checked against Getty's live Linked Art SPARQL endpoint
(`data.getty.edu/museum/collection/sparql`) and 40 of them didn't match this
sheet's original `artists.xls`-derived number — see `DATA/artist_works_5to25.csv`
for the actual title list each corrected count is based on. Those 40 rows'
`By Century` column is the original, uncorrected breakdown and may no longer sum
to `Total Works`.

**224 artists** qualify (out of 1240 total in this century range).
